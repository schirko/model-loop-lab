Can AI build better AI?

A program builds ten models, scores them, keeps the best three, changes them a little, and goes again. This project runs that loop on Colorado forest data, measures how much each generation improves, and then shows a loop that gets worse instead.

Two experiments

The loop works

An evolutionary search breeds better model settings over 20 generations. It is then raced against Optuna, a standard tuning library, and plain random guessing.

See the improvement loop

Where loops break

A model learns the data, writes new data, and the next model learns only from that. After a few rounds the data loses its variety and accuracy on real forest plots falls.

See the collapse

The data

The Forest Covertype dataset comes from the Roosevelt National Forest in northern Colorado. Each row is a 30 by 30 meter plot described by map features: elevation, slope, aspect, distance to water, roads and past fire points, wilderness area and soil type. The label is which of seven tree covers grows there, such as spruce-fir or lodgepole pine.

The full set has about 581,000 plots. The loops use a fixed sample of 20,000 so each generation trains in seconds, with a separate held-out set for every score shown on this site.

Source: Blackard and Dean, U.S. Forest Service and Colorado State University, via the UCI Machine Learning Repository and scikit-learn's fetch_covtype.

How it was built

Python with pandas, scikit-learn and Optuna. Each step is worked through in a Jupyter notebook, with the result and a plain-language reading under every chart. The notebooks write small results files, and this site draws its charts from them.
