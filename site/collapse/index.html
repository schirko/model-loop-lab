Where loops break

Some AI models are now trained partly on text and data written by earlier models. This experiment shrinks that idea down to forest data: each generation learns only from what the previous generation made up, never from the real plots again.

  1. LearnA generator model learns the shape of the forest data.
  2. Make up dataIt writes 20,000 new, synthetic forest plots.
  3. TestA classifier trains on those synthetic plots and is scored on real ones it never saw.
  4. Hand offThe next generator learns from the synthetic plots only.

Then back to step 1, for 10 generations. Generation 0 learns from the real data, every later one from the one before it.
