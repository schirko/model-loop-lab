The notebooks

The project is four Jupyter notebooks, one per question. Each one shows the code, its output, and a plain-language reading of what the output means.

In order

  • 01. Data and baseline

    Finished

    The Colorado forest data and its lopsided cover types, a fair sample and split, guessing against a plain decision tree, the 77.2% baseline, overfitting, which cover types it misses, and why neighbors get confused. Ten steps.

  • 02. The evolution loop

    Planned

    Builds the build, score, keep, change loop and runs it for 20 generations, logging every model it tries.

  • 03. Racing the loop against Optuna and random guessing

    Planned

    Gives three search methods the same 200-model budget and compares how fast each finds good settings.

  • 04. Model collapse

    Planned

    Trains each generation only on the previous generation's made-up data, and measures what happens to accuracy on real plots and to the variety in the data.

Each notebook opens here as a web page once it has been run, with every step's code, output and explanation. The source notebooks are in the GitHub repository.
